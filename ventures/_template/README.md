# Venture folder

Copy this folder and rename it to your concept slug, for example
`ventures/tidal-energy-leasing/`. Then run:

```
/architect-custom tidal-energy-leasing
```

The session writes its outputs here as it goes: the venture design record, the
customer theory map, the activity outcome map, the financial simulation, and a
conductor report showing where you are in the sequence.

Do not create these files by hand. The method makes them.
