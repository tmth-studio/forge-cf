# Forge WS1 — Regression set

Every defect found in a graded run becomes a one-line assertion here. A future run **must keep every check passing** — this is what stops the CF-development loop from circling (fixing G1 by reintroducing a previously-fixed defect). Grouped by challenge / scope. Seeded from Run 0 (2026-06-02).

**How to use:** after each run, walk every assertion. Any FAIL is either a regression (the run broke a previously-passing check) or a still-open baseline gap (acceptable only if explicitly carried). Log results next to the score-trend row in `README.md`.

## R2 — foregone cost and the value ceiling (added 2026-08-27 — VA-63)

- [ ] **R-R2a (VA-63):** No run may present foregone/opportunity-cost value as **outside** or **alternative to** Simanis WTP. Foregone is one of the four cost classes (`Expended · Foregone · Risk-borne · Friction`) and sits inside WTP by construction. Any sentence of the form "X is not Simanis WTP because Simanis anchors to the current routine", applied to a foregone loss, is a FAIL.
- [ ] **R-R2b (VA-63):** Where a revealed price exceeds the recorded band for a loss already sized, the run **reconciles them as one component** — "the record sized [component] at [band]; [source] re-sizes the same component at [figure]". Creating a second category to hold the excess ("upside beyond WTP", "venture-created value") is a FAIL, because it removes the value from the ceiling.
- [ ] **R-R2c (VA-63):** Where two figures are carried, the run gates on the evidenced figure, states the larger as a **permitted ceiling**, and names the **specific test that would promote it** (A/B at a live site, first-portfolio measurement, quoted price). Averaging the two, silently adopting the larger, or stating a permitted ceiling with no named conversion test, is a FAIL.
- [ ] **R-R2d (VA-63, added same day after two live catches):** A foregone item is sized as **blocked return × capture probability**, with both parameters recorded and flagged. Two FAILs: (a) excluding it because "the customer chose not to spend that money" / "the economy carries it, not the business"; (b) entering the avoided outlay gross as the loss. The un-made spend is neither the loss nor zero. Entering a foregone item with no capture probability is an OCV L5 failure.
